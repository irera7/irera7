Today I build AI-powered products with multi-agent teams: AI coding agents open the pull requests on my product repos, and I review and merge them. ### 🌐 Network & infrastructure

I've worked as a network & infrastructure engineer since 2013, and I run my own products the same way:

- **Multi-vendor network automation:** LumexNet covers MikroTik (RouterOS API), Cisco, Ubiquiti airOS/UniFi and SNMP devices from one panel. It handles reachability, CPU, memory, disk and port monitoring, parent-aware alert suppression, daily config backups with diff, and vulnerable-version audits.
- **Changes are approved by hand:** scripts are generated but applied only after approval, with rollback. Secrets live in a local encrypted store and are never sent to the cloud.
- **Self-hosted production:** each product runs as a Docker Compose stack (Postgres, Redis, migrate job, API, worker, web). Only the web port is exposed, behind an nginx reverse proxy and ArvanCloud CDN.
- **Real-time and media:** a self-hosted LiveKit node for voice/video, RTSP/NVR camera ingest for on-prem CCTV analytics.
- **Privacy by architecture:** on-device pose estimation (LumexFit), on-prem LLMs (Lumex Agent OS), backups that never leave the machine (LumexNet).
